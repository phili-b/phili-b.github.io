02Featured work

  • kernel

    Mira220 Linux driver

    A V4L2 subdevice driver for the ams OSRAM Mira220, a 1600×1400 global shutter sensor. It supports mono and RGB at 8, 10 and 12 bits, up to 1500 Mbit/s per lane and 90 fps, with device tree overlays for Raspberry Pi. I'm upstreaming it to the Linux media subsystem, alongside a driver for the Mira016.

    C · Linux kernel · V4L2 · device tree

    Code →Upstream patches →
  • ISP

    fast-openISP GUI

    A software image signal processor with a Windows desktop GUI, built on fast-openISP. It loads raw Bayer images (RAW, TIFF, DNG), runs 17 switchable ISP blocks with a live preview and before/after split view, and calibrates the colour correction matrix on a ColorChecker, reporting ΔE2000 per patch. It ships as a single exe, with a CLI and a typed Python API.

    Python · image processing · colour science

    Code →Docs →Download →
  • embedded

    Teensy NanEyeC

    Streams 320×320 mono or colour images from an ams OSRAM NanEyeC to a PC through a Teensy 4.1, over the sensor's single-ended SEIM interface. It runs at 35.5 fps with no lost frames, and does demosaicing, white balance and gamma correction on the host. I built it with Claude Code.

    C++ · Python · Teensy · embedded
